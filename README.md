## 🏛 Архитектура системы

Система состоит из 3 независимых микросервисов, API Gateway и отдельных экземпляров баз данных PostgreSQL для каждого сервиса.

```
                        ┌────────────────────────┐
                        │      API Gateway       │
                        │        (Nginx)         │
                        └───────────┬────────────┘
                                    │
           ┌────────────────────────┼────────────────────────┐
           ▼                        ▼                        ▼
┌────────────────────┐   ┌────────────────────┐   ┌────────────────────┐
│   User Service     │   │   Movie Service    │   │  Booking Service   │
│   (Port: 8001)     │   │   (Port: 8002)     │   │   (Port: 8003)     │
└──────────┬─────────┘   └──────────┬─────────┘   └──────────┬─────────┘
           │                        │                        │
     [ DB: users ]            [ DB: movies ]           [ DB: bookings ]
```

### 1. User Service (Сервис пользователей)
* **Назначение:** Регистрация, аутентификация и управление профилями пользователей.
* **База данных:** PostgreSQL (`db_users`)

#### Модель данных (Users):
* `id` (UUID / INT, PK)
* `email` (String, Unique)
* `password_hash` (String)
* `full_name` (String)
* `role` (Enum: `USER`, `ADMIN`)
* `created_at` (Timestamp)

#### Эндпоинты:
* `POST /api/v1/auth/register` — Регистрация нового пользователя.
* `POST /api/v1/auth/login` — Вход в систему (возвращает JWT-токен).
* `GET /api/v1/users/me` — Получение данных текущего пользователя (требует JWT).
